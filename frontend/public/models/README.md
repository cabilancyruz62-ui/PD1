# Optional Blender exports

The app includes procedural Labrador, Beagle, and Dalmatian models. To replace the matching model in Settings > 3D Patient's inspector, export:

- `labrador.glb`
- `beagle.glb`
- `dalmatian.glb`

Missing exports retain the built-in breed model. The camera overlay currently uses the shared procedural rig so its standing/lying transitions remain available. See [model conventions and alignment](../../../docs/DOG_MODELS.md) before exporting a final rig.
