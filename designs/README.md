# PupVitals tracking designs

Store the source code, configuration, reference assets, and experiment notes for each dummy-limb tracking design in its own folder.

| Folder | Design |
| --- | --- |
| [design-1-aruco](design-1-aruco/) | Marker-based computer vision using OpenCV ArUco |
| [design-2-orb-ransac](design-2-orb-ransac/) | Feature-based markerless tracking using ORB and RANSAC homography |
| [design-3-optical-flow](design-3-optical-flow/) | Optical-flow tracking; exact algorithm to be selected |

These folders are starting points for development. Tracking implementations have not been added yet.

Keep Blender source files in `AR model/` and the final application model at `frontend/public/models/canine.glb`.
